## 保护与边界

远端只允许固定模板 SELECT，通过 HTTP GET 访问唯一老师库地址。不执行远端写入、DDL、授权、持久设置或结构变更。
单条查询继续保留 500 条、单线程、8192 行块、15 秒、100 万读取行、128 MiB 读取字节限制，未提高任何原有上限。

本地保守预算：

| 项目 | 上限 |
|---|---:|
| 每次运行请求数，含连接检查 | 150 |
| 每次运行累计读取行数 | 2000 万 |
| 每次运行累计读取字节 | 512 MiB |
| 滚动一小时请求数 / 读取行数 / 字节 | 200 / 2000 万 / 512 MiB |
| 滚动一天请求数 / 读取行数 / 字节 | 500 / 4000 万 / 1 GiB |
| 请求开始间隔 | 至少 3 秒 |

发起下一条请求前预留原单条查询的整份读取上限，余量不足则暂停。发出 GET 前将请求及保守读取预留写入本地流量记录；异常退出不抹去已发生的流量。
成功后用服务端 statistics 校正消耗。无法取得读取统计、认证/权限失败、HTTP 429 或明确服务端保护错误立即停止。
普通失败保留到下次显式恢复，不在同次运行反复重试；连续两批失败停止。
成功查询若读取达到 20 万行、16 MiB 或服务端耗时 6 秒，也会在下一条查询前提前暂停。

预算会使一轮提前停下并保留队列，不承诺同一次运行完成 463 个初始范围及其拆分。
流量记录只覆盖这个新采集器，不能代表老师账户剩余配额，也不包含旧采集器过去已消耗的流量。
用户不知道平台额外配额。ClickHouse 的保护可能在数据块/数据部件处理后才检查，因此不能保证绝对零触限，尤其不能推断未知的账户/平台配额。
依据：[ClickHouse 查询保护](https://clickhouse.com/docs/operations/settings/query-complexity)、[配额说明](https://clickhouse.com/docs/operations/quotas)。
