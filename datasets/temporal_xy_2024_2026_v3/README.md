# Temporal X/Y v3

Train 1,193 groups. Validation 268 groups. Test 169 groups.

Each group identifies a GitHub account and a cutoff.
X references pre-cutoff file contributions.
Y lists verified post-cutoff Issue closures.

This directory contains the handoff indexes and contribution metadata.
source_manifest.json identifies the original source packages.
Code, Issue text, and evidence replay require access to those packages.
The 2026 Q4 test groups have incomplete follow-up.
