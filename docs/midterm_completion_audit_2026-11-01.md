## 必须先对齐的算法口径

原中期计划要求原版文件级 CODER（含 CodeBERT），明确不能以简化模型挂名替代。

main 的 `docs/data-and-model.md` 则明确实现是 Developer–Issue–Repository 的 CODER-inspired 模型，编码器为固定 MiniLM；`CODER/AGENTS.md` 同样明确不是原版 Developer–Code File 严格复现。这是研究目标/验收口径差异，需要团队确认最终采用哪个目标并统一答辩材料。

不能说 C 没做模型：当前文档记录正式运行 `coder-full-search8-v1`、8 个 trial、独立模型包路径与离线指标。但这些成绩不等于原计划要求的原版 CODER 复现，且本机未重新加载队友模型包验证。

该文档还明确记录：GAT 图包含训练截止后创建的 19,882 个 Issue 结构边和 22,732 条标签边，不满足严格时序结构可见性。正式对比前需新版本修复、重训和复评，或在调整后的研究口径中明确披露，不能把旧结果视作无泄漏验收通过。
