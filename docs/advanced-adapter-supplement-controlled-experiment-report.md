# Adapter v1 补采数据受控实验报告

## 最终结论

本轮按照冻结边界完成了权重、负样本、cutoff 和多 seed 实验。表现最好的新方案是
`C1-N2-safe`：只使用季度截断补采样本、每个 outcome 等权，并为每条构造 20 个 cutoff-safe
对照。它在 validation 上稳定优于 RC1 round2 的综合选择分，但在锁定后的 RC1 test 上未通过
晋级门槛，因此不替换当前 shadow Adapter。

锁定模型为 seed `20261103`：

- RC1 test MRR：`0.26205`，低于门槛 `0.26301`；
- pair accuracy：`60.09%`，略高于门槛 `60.05%`；
- 未见开发者 MRR：`0.27044`，较基线 `0.27205` 小幅下降；
- 低覆盖画像 MRR：`0.21540`，较基线下降 `0.01293`，超过允许的 `0.01`；
- 全未知画像回退最大误差：`0.0`。

因此本轮结果保留为 research 模型，不进入 shadow。

## 冻结边界

- 基础模型固定为 `coder-full-search8-v1`；
- 23 维画像名称、顺序、mask 和缺失值规则未修改；
- RC1 validation/test 未修改，分别保持 7,420 和 4,240 个比较对；
- 384 条完整补采 outcome 只进入 train，8 条不完整样本继续排除；
- 训练 seed 不改变候选采样 seed `20261102`；
- E2、E3、C1、C5 和多 seed 选择阶段均未评估 test；
- 仅在 C1 多 seed winner 锁定后评估一次 RC1 test。

## 第一阶段：outcome 权重

E2 使用：

```text
pair weight = outcome type weight / comparison count
```

E3 在 E2 基础上将单个 pair 权重上限设为 `0.25`。这会限制只有 1～3 个对照的 outcome
产生过大的单步梯度；84 个 pair 触发上限。

| 实验 | Validation MRR | 综合选择分 | 未见开发者 MRR | 低活跃 MRR | 低覆盖 MRR | 同仓库准确率 |
|---|---:|---:|---:|---:|---:|---:|
| E0 RC1 round2 | **0.25019** | **0.25225** | 0.24690 | 0.18705 | **0.24711** | 50.00% |
| E1 直接混合 | 0.24314 | 0.24166 | **0.25818** | 0.15292 | 0.20521 | 50.00% |
| E2 outcome 等权 | 0.24029 | 0.22994 | 0.23614 | 0.14012 | 0.18474 | 46.15% |
| E3 等权 + pair cap | 0.24136 | 0.22968 | 0.22686 | 0.14297 | 0.18143 | 48.08% |

E2/E3 均未超过 E0，说明问题不只是原先 1～5 对照与 20 对照的权重不平衡。

## 第二阶段：cutoff-safe 分层负样本

季度 cutoff 能找到足够的精确历史候选。候选文本和 hash 均来自该 cutoff 的已验证快照，候选
生成 seed 固定为 `20261102`。每个 outcome 的目标结构为：

- 5 个同仓库；
- 5 个跨仓库语义技术栈近邻；
- 5 个基础 CODER 高分困难对照；
- 5 个随机对照。

共生成 194 个季度 outcome、3,880 个比较对和 1,781 个候选历史版本。由于没有冻结的版本化
Issue 语言字段，“同技术栈”使用 cutoff 时刻标题/正文编码的相似度代理，不使用未来元数据。

真实数据中有 38 个 outcome 在精确 cutoff 找不到 5 个同仓库 Issue。系统没有伪造候选，而是
逐条记录短缺并使用其余 cutoff-safe 候选确定性补齐到 20 个。实际类别数量为：

| 类别 | 数量 |
|---|---:|
| 同仓库 | 891 |
| 语义技术栈代理 | 970 |
| 基础 CODER 困难对照 | 970 |
| 随机对照 | 970 |
| 短缺补位 | 79 |

PR 创建前一秒的样本只有当时的 1～5 个精确快照，无法在不发明历史文本的前提下扩展到 20
个。因此没有声称完成“全量严格 N2”。C1 使用季度分层方案；C5 使用“季度 N2-safe + PR
前一秒 N0”的证据安全混合方案。

## 第三阶段：cutoff 实验

| 实验 | 训练安排 | Validation MRR | 综合选择分 |
|---|---|---:|---:|
| C1-N2-safe | 仅季度、20 对照、outcome 等权 | **0.24930** | **0.25406** |
| C5-safe hybrid | 季度 N2-safe + PR 前一秒 N0，权重 2:1 | 0.22956 | 0.22524 |

C1 的综合分高于 E0，C5 明显退化，因此 C1 进入多 seed，C5 被淘汰。

## Supplement test 可行性审计

现有数据不足以建立方案要求的独立 supplement test：

- 补采开发者：59 人；
- 现有 RC1 test 仅覆盖 12 人、16 条 outcome；
- 只有 1 人达到 3 条 outcome，没有人达到 5 条；
- 平均每人 1.33 条；
- RC1 validation 另有 15 人、22 条，但已参与模型选择，不能重新包装成独立 test。

在这 16 条只读诊断子集上，C1 MRR 从 `0.13551` 升至 `0.13699`，但 mean rank 从
`10.25` 变为 `10.63`，跨仓库 pair accuracy 也下降，因此不能称为明确提升。

要完成正式 supplement test，A 仍需为更多补采开发者采集训练期之后的独立 outcome，并为每条
提供同一套 cutoff-safe 20 候选快照。至少需要让尽可能多的 59 人达到每人 3～5 条；这些数据
不得进入训练或 validation。

## 晋级判定

| 门槛 | 结果 |
|---|---|
| Test MRR 不低于 0.26301 | 失败：0.26205 |
| Pair accuracy 不低于 60.05% | 通过：60.09% |
| 未见开发者不明显退化 | 基本持平：-0.00161 |
| 低覆盖下降不超过 0.01 | 失败：-0.01293 |
| Supplement test 明确提升 | 无法验证：正式专项集不存在 |
| 5 seed 至少 4 个方向一致 | 通过：选择分 5/5、MRR 4/5 |
| 全未知回退误差为 0 | 通过 |
| 无时间、身份泄漏 | 通过现有审计；同仓库短缺已显式披露 |

综合判定：`REJECT_SHADOW_PROMOTION`。
